# React Fundamentals — CommunityHub Frontend

## 📘 Overview
This week focused on mastering **React**, the most popular library for building user interfaces.  
I learned how to set up a React project using **Vite**, create reusable components, manage state with hooks, and handle events to make the UI interactive.

---

## 🧩 Lessons Covered
### Lesson 15 — Introduction to React
- Setting up React with Vite
- Understanding JSX and component structure
- Creating reusable components
- Passing props and rendering dynamic content
- Component composition using `children`

### Lesson 16 — State & Events in React
- Managing state with the `useState` hook
- Handling events and controlled forms
- Updating arrays and objects immutably
- Lifting state up between components
